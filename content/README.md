# 📄 Read me

This repository contains the source code for my Obsidian Vault, published via **Quartz 5.0**. It follows a strictly organized PARA + Zettelkasten hybrid system to ensure high data-availability and low mental friction.
For more info about notes management check this : 👉  [PARA]() + [Zettelkasten]().

---

## 📂 Folder Structure (The Blueprint)

My vault is organized into five primary directories to keep things actionable:

*   **`00 Projects/`** — Active missions with a deadline.
*   **`01 Areas/`** — Ongoing responsibilities (Backend Architecture).
*   **`02 Resources/`** — Knowledge inputs and curated "Backlog" items.
*   **`03 Permanent/`** — My Zettelkasten. Long-term, atomic, and interconnected thoughts.
*   **`04 Archives/`** — Completed quests and "Retired" data.

---

## 📊 Database Logic (Bases)

To handle high-volume data like my book list, movie backlog, and course tracking, I use **Bases**. 

- **Areas-base:** Tracks ongoing university semesters and GPA goals.
- **Resources-base:** My central "Inbox" for books, series, games, and URLs that I'm recently using.
- **Permanent-base:** Indexes atomic notes that I made by myself with the was that more convenient with me.

*Note: These Bases are interactive in Obsidian but rendered as static tables or links in the Quartz web view.*
