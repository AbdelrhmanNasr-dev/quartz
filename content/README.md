# 📄 README

This repository contains the source code for my Obsidian Vault, published via **Quartz 5.0**. It follows an organized PARA + Zettelkasten hybrid system to ensure high data-availability and low mental friction.
For more info about notes management check this : 👉  [PARA]() and [Zettelkasten]().

---

## 📂 Folder Structure (The Blueprint)

My vault is organized into five primary directories to keep things actionable:

*   **`00 Projects/`** — Active missions with a deadline.
*   **`01 Areas/`** — Ongoing responsibilities (Backend Architecture).
*   **`02 Resources/`** — Knowledge inputs and future projects that will be seen later.
*   **`03 Permanent/`** — My Zettelkasten. Long-term, atomic, and interconnected thoughts in my       way and by my hands.
*   **`04 Archives/`** — Completed quests and past projects.

---

## 📊 Database Logic (Bases)

To handle high-volume data like my book list, course tracking, I use **Bases**. 

- **Areas-base:** Tracks ongoing goals and important areas in my life.
- **Resources-base:** My central Inbox for books, courses, projects, Apps and URLs that I'm recently using.
- **Permanent-base:** Indexes atomic notes that I made by myself with the was that more convenient with me.

*Note: These Bases are interactive in Obsidian but rendered as static tables or links in the Quartz web view.*
