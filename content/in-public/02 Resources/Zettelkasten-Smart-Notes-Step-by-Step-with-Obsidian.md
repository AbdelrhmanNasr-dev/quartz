# Zettelkasten Method

> [!abstract] Overview
> This video demonstrates how to implement the Zettelkasten method (smart notes) entirely within Obsidian. It provides a practical, step-by-step workflow starting from an empty vault, showing how to create folder structures, templates, and link notes to synthesize knowledge for creative output like blog posts.

## 📂 Vault Structure & Core Concepts

The system relies on creating a specific folder hierarchy for the different stages of note processing:

1. **Fleeting Notes:** Used for capturing quick ideas, highlights from the web, and unrefined thoughts.
2. **Literature Notes:** The space where you synthesize fleeting notes, adding deeper thinking, and phrasing concepts in your own words.
3. **Permanent Notes:** Where refined ideas are stored in your "slip box." These are linked to other permanent notes to form webs of knowledge (the core of the Zettelkasten).
4. **Templates:** A folder dedicated to storing structure layouts (e.g., Note Templates, Map of Content templates) to standardize creation.
5. **Projects:** Where you pull together permanent notes to create final outputs like blog posts, articles, or scripts.

## 🛠️ Step-by-Step Obsidian Workflow

The video outlines a practical process from content consumption to final output:

### 1. Setup & Templating
- Enable the **Templates Core Plugin** in Obsidian settings and point it to the Templates folder.
- Create a `Note Template` that automatically generates the title, creation date, a section for references, and a space for the note body.
- Set up a `Map of Content (MOC)` template using a numbered list to outline broader themes.
- Change Obsidian settings so new links create files in the "same folder as current file" to keep the structure clean.

### 2. Processing an Article (The Flow)
- **Capture (Fleeting):** Read an article and drop quick highlights into a Fleeting Note using the template.
- **Synthesize (Literature):** Open a split pane. Look at the Fleeting Note and write out the concepts in your own words in a Literature Note, adding your personal thoughts.
- **Connect (Permanent):** Break down the Literature Note into atomic Permanent Notes (e.g., *What is Bootstrapping?*, *Benefits of Bootstrapping*). 
- **Traceability:** Always link the Permanent Note back to the Literature Note, which is linked to the Fleeting Note, ensuring you never lose the original source context.

### 3. Organizing with Maps of Content (MOCs)
Instead of relying solely on folders, the video uses Maps of Content to group related permanent notes. By linking individual permanent notes back to a centralized MOC (like "Bootstrapping a Startup"), you create structured entry points into your slip box.

### 4. Creating Output (Projects)
The ultimate goal of the Zettelkasten is output. 
- Create a new note in the Projects folder (e.g., a blog post outline).
- Use Obsidian's embed feature (`![[Note Name]]`) to pull the full text of your Permanent Notes directly into the outline. 
- This allows you to view the raw material inline while you write the final draft around it, ensuring you are never staring at a blank page
